1. Ringkasan Eksekutif & Tujuan Produk

Website ini adalah platform portfolio digital satu halaman (Single-Page Application / vCard) bertema gelap (Dark Mode) yang dirancang untuk mempresentasikan identitas profesional, keahlian teknis (Full-Stack Development & Manufacturing IT), riwayat pengalaman, dan studi kasus sistem yang telah dibangun.

  • Tujuan Utama: Memberikan kesan pertama yang kuat dalam waktu < 10 detik, memvalidasi kompetensi teknis melalui bukti proyek nyata, serta mempermudah konversi kontak (undangan wawancara atau konsultasi proyek).
  • Indikator Keberhasilan (KPI): Pengunjung dapat mengunduh CV dalam 1 klik, memfilter studi kasus proyek berdasarkan kategori tanpa page reload, dan mengirimkan pesan kontak secara langsung.

2. Arsitektur Desain & Spesifikasi Visual (Design System)

A. Tata Letak Utama (Layout Architecture)

Website menggunakan arsitektur Split-Screen Fixed Sidebar + Dynamic Content Area di layar desktop (>= 1024px) dan berubah menjadi Top Header + Drawer Menu di perangkat mobile/tablet (< 1024px).

  1. Panel Kiri — Fixed Identity Sidebar (Lebar ~28%–30% atau maksimal 380px): Bersifat statis (sticky) saat halaman berpindah menu. Memuat foto profil bulat (180px × 180px), Nama Lengkap, Jabatan Utama, ikon sosial media (GitHub, LinkedIn, WhatsApp/Email), tombol CTA utama (Download CV), dan teks Copyright.
  2. Panel Kanan — Dynamic Content Canvas (Lebar ~70%–72%): Area utama tempat konten dirender berdasarkan navigasi hash (#home, #about-me, #resume, #portfolio, #blog, #contact) dengan transisi halaman halus (smooth slide/fade animation).
  3. Navigasi Ikon Mengambang (Floating Icon Navigation): Terletak di sisi paling kanan berupa tombol ikon vertikal dengan tooltip label menu saat di-hover.

C. Tipografi (Typography)

  • Font Heading & Navigasi: Poppins (Semi-Bold 600 & Bold 700). H1: 48px (Desktop) / 32px (Mobile); H2: 32px dengan aksen warna utama; H3: 21px.
  • Font Body & Deskripsi: Open Sans atau PT Sans (Regular 400, 15px, line-height 1.65).
  • Font Teknis (Opsional): JetBrains Mono atau Consolas (13px) untuk badge tech stack pada kartu portfolio.

3. Spesifikasi Fungsional Per Section

Section 1: Home (#home)

  • Tata Letak: Teks rata tengah (centered vertically & horizontally) di atas latar gelap dengan efek subtle geometric/particle overlay.
  • Komponen: Nama Lengkap (H1) dan Text Rotator (animasi pergantian peran setiap 3 detik, misalnya: Full-Stack Web Developer, Manufacturing & PPIC System Specialist, Database & Linux Server Admin).

Section 2: About Me (#about-me)

  • Profil & Biodata (2 Kolom): Kolom kiri (60%) berisi ringkasan eksekutif pengalaman membangun sistem informasi perusahaan; Kolom kanan (40%) berisi daftar key-value beraksen (Domisili, Status Ketersediaan, Email, Telepon/WhatsApp).
  • What I Do (Grid 2×2): 4 kartu layanan inti dengan line icon: (1) Enterprise Web Applications, (2) Manufacturing & PPIC Systems, (3) Real-Time Monitoring & Automation, (4) Database Architecture & Server Deployment.
  • Fun Facts / Statistik (Grid 3 Kolom): Kartu metrik pencapaian (Sistem Terdeploy, Tahun Pengalaman IT, Proyek Selesai).
Catatan Desain: Komponen Testimonials, Clients Logo, dan Pricing Plans pada template bawaan bersifat opsional dan dapat dinonaktifkan (display: none) jika fokus utama website adalah lamaran kerja profesional.

Section 3: Resume (#resume)

  • Kolom Kiri (60% — Timeline & Kredensial): Experience Timeline (tahun, perusahaan, jabatan, pencapaian teknis), Education Timeline, dan Certificates (grid 2 kolom berisi institusi, nama sertifikat, tanggal terbit, dan ID kredensial).
  • Kolom Kanan (40% — Skills & Domain Knowledge): Skill Progress Bars (Backend & Database, Frontend & Infrastructure) dan Knowledges Tag Cloud (PPIC, WIP Tracking, Standard Cycle Time, ERD Design, REST API, Nginx Reverse Proxy).

Section 4: Portfolio (#portfolio)

  • Filter Kategori: Tombol filter interaktif (All, Enterprise & PPIC, Web Applications, Automation & IoT) berbasis Shuffle.js.
  • Grid Proyek (2 atau 3 Kolom): Kartu dengan thumbnail rasio 4:3, judul proyek, kategori, dan efek overlay saat di-hover.
  • Modal Detail Studi Kasus: Pop-up (Magnific Popup) berisi carousel screenshot, deskripsi masalah & solusi bisnis, daftar Tech Stack, tanggal pengerjaan, serta tautan ke Live Demo atau Repository GitHub.

Section 5: Blog / Technical Notes (#blog) — Opsional

  • Grid 2 kolom berisi kartu artikel atau catatan studi kasus teknis (thumbnail, kategori, tanggal, judul). Dapat disembunyikan jika belum digunakan.

Section 6: Contact (#contact)

  • Kolom Kiri (35%): 4 kartu informasi vertikal dengan ikon (Kota/Domisili, Telepon/WhatsApp, Email, Status Open to Work / Freelance).
  • Kolom Kanan (65%): Form kontak interaktif (Full Name, Email Address, Subject, Message) dengan validasi input, proteksi spam, dan notifikasi AJAX tanpa reload halaman.

4. Persyaratan Teknis & Performa (Non-Functional Requirements)

  1. Responsivitas (Mobile-First Compatibility): Proporsional pada ukuran 360px (Mobile), 768px (Tablet), dan 1440px+ (Desktop) dengan slide-out drawer menu di perangkat mobile.
  2. Kecepatan Muat (Performance): Seluruh gambar dikompresi ke format WebP atau JPG teroptimasi (< 200 KB per gambar) dengan target skor Google Lighthouse Performance >= 90.
  3. Arsitektur Hosting & Deployment: Dibangun sebagai static frontend (HTML5, CSS3, JS/jQuery) untuk deployment di GitHub Pages, Vercel, Netlify, atau Nginx. Form kontak menggunakan API pihak ketiga (Web3Forms / Formspree) menggantikan skrip PHP bawaan.
  4. SEO & Metadata: Dilengkapi tag <title>, <meta name="description">, serta Open Graph tags (og:title, og:image, og:description).

5. Kriteria Penerimaan (Acceptance Criteria)

  • Navigasi hash (#home s/d #contact) berfungsi mulus di desktop maupun mobile tanpa broken link.
  • Tombol Download CV mengunduh file PDF terbaru dengan nama file yang rapi (contoh: CV_NamaAnda_FullStackDeveloper.pdf).
  • Filter kategori pada halaman Portfolio menyaring kartu proyek dengan animasi halus dan modal detail menampilkan informasi lengkap.
  • Form Contact berhasil mengirimkan pesan uji coba ke email tujuan dan menampilkan pesan konfirmasi.
  • Tidak ada teks placeholder ("Lorem ipsum", "Alex Smith", atau gambar bawaan template) yang tertinggal di seluruh halaman.
